Task: Убрать роботизированность речи, починить прекращение ответов (429) и скролл чата

Work Log:
- Диагностика через 6 сообщений подряд + dev.log: найден точный виновник — POST /api/chat падал с 429 Too many requests; причина: 3 LLM-вызова на каждое сообщение (чат + extractMemories + updateDiary), очистка чата помогала из-за меньшего числа токенов
- Голос v3: восстановил /api/tts на базе Google Translate TTS (tl=ru, client=tw-ob, UA+Referer) — естественный русский нейроголос вместо роботизированного системного; LRU-кэш 150 фраз, 3 ретрая с backoff, разбивка длинных фраз по ~190 символов, MP3-склейка
- use-tts-queue v3: авто-режим — серверный Google-голос основной, при сбое (2 неудачи подряд → cooldown 90с) автоматический fallback на системный синтез; эмоции теперь через Web Audio playbackRate (меняет темп+тон вместе — естественная просодия: восторг 1.08, сочувствие 0.92, задумчивость 0.90, мужской тембр 0.92) + детерминированный джиттер ±2%
- /api/chat анти-429: HISTORY_LIMIT 16→12, обрезка реплик истории до 500 символов, MEMORY_LIMIT 30→15; extractMemories — только при маркерах фактов (FACT_HINT_RE: «меня зовут», «люблю», «планирую»…) и не чаще 15с; diary — каждый 3-й ответ за день + не чаще 30с; ретраи основного чата до 3 раз (3с/6с); при полном сбое — 503 с понятным текстом; при обрыве стрима — видимая пометка «(связь с моделью оборвалась)» в чате вместо тишины
