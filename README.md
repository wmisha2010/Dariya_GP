# Дария — голосовой ИИ-ассистент для браузера

Веб-аналог Dewiar / Алисы: нажимаете на микрофон, говорите — Дария слушает, отвечает голосом,
управляет музыкой и радио, открывает YouTube и помнит, о чём вы говорили.

**Текущая версия: v2.5**

## Возможности

- 🎙 **Голосовой ввод** — Web Speech API (Chrome / Edge), микрофон включается кнопкой и слушает, пока вы его не выключите.
- 🔊 **Озвучка ответов** — TTS через Microsoft Edge (естественный русский голос, очередь фраз).
- 🛡 **«Эхо-щит»** — ассистент не слышит саму себя: пока она говорит или играет музыка, посторонний звук не вызывает ложных команд; команды «выключи …» во время воспроизведения обрабатываются отдельно.
- 🎵 **Музыка и интернет-радио** — поиск станций через каталог radio-browser.info, стриминг через серверный прокси `/api/music` (обход CORS и HTTPS-ограничений).
- ⏹ **Команды остановки** — «выключи музыку / радио / ютуб» именно останавливают воспроизведение, а не переключают трек или станцию.
- ▶️ **YouTube** — воспроизведение аудио во встроенном плеере; если источник заблокирован — фолбэк: ссылка/кнопка открытия в официальном YouTube.
- 🧠 **ИИ-мозг** — OpenRouter и Google Gemini с автоматическим фолбэком (`src/lib/openrouter.ts`, `src/lib/gemini.ts`), ключи задаются в `.env`.
- 💾 **Память и дневник** — факты о пользователе, краткие записи разговоров по дням, история чата, несколько ИИ-персонажей (Prisma + SQLite).
- 📱 **PWA** — устанавливается на телефон как приложение (иконки, manifest, service worker).

## Технологии

| Слой | Стек |
|---|---|
| Фреймворк | Next.js 16 (App Router) + TypeScript |
| UI | Tailwind CSS + shadcn/ui |
| БД | Prisma ORM + SQLite |
| TTS | msedge-tts (серверный синтез речи) |
| Распознавание речи | Web Speech API (браузерное) |
| Аудио | HTMLAudioElement + серверный стрим-прокси |

## Быстрый старт

Требуется Node.js 20+.

```bash
# 1. Зависимости
npm install

# 2. Настроить окружение
cp .env.example .env
# при необходимости укажите ключи OPENROUTER_API_KEY / GEMINI_API_KEY

# 3. Создать базу данных (SQLite)
npm run db:push

# 4. Запустить в режиме разработки
npm run dev
# → http://localhost:3000
```

> ⚠️ Доступ к микрофону браузеры дают только на `localhost` или по **HTTPS** — на «голом» HTTP по IP микрофон работать не будет.

## Структура проекта

```
src/
├── app/
│   ├── page.tsx                  # Главный экран: логика ассистента, команды, эхо-щит
│   ├── layout.tsx                # Метаданные, PWA-регистрация
│   └── api/
│       ├── chat/route.ts         # ИИ-диалог (OpenRouter → Gemini, фолбэк)
│       ├── tts/route.ts          # Синтез речи (msedge-tts)
│       ├── music/route.ts        # Поиск радиостанций (radio-browser.info)
│       ├── music/stream/route.ts # Прокси аудиопотоков
│       ├── messages/route.ts     # История чата
│       ├── memory/route.ts       # Память ассистента
│       ├── diary/route.ts        # Дневник разговоров
│       └── characters/route.ts   # ИИ-персонажи
├── hooks/
│   ├── use-speech-recognition.ts # Голосовой ввод (Web Speech API)
│   ├── use-tts-queue.ts          # Очередь озвучки ответов
│   ├── use-audio-player.ts       # Радио/музыка + сторожевой таймер (watchdog)
│   └── use-youtube-audio.ts      # Аудио YouTube + фолбэк в официальный плеер
├── components/daria/             # UI: чат, плеер, настройки, память, орб и т.д.
└── lib/                          # Клиенты: db (Prisma), openrouter, gemini
```

## Что не входит в репозиторий

- `.env` — ключи и локальные пути (есть шаблон `.env.example`);
- `db/custom.db` — ваша база с историей переписки (создаётся через `npm run db:push`);
- `models/piper/irina.onnx` — локальная TTS-модель, в коде не используется (устаревший эксперимент);
- `node_modules`, `.next` — восстанавливаются установкой и сборкой.
